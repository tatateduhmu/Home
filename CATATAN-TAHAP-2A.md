# Catatan Tahap 2A (revisi 2) — perbaikan visual & responsive minimal

Acuan visual: ZIP website asli. Karosel klien dan testimoni dikembalikan ke perilaku/tampilan asli.

File berubah dari ZIP asli: style.css, site.js, carousel.js, index.html, dan skip link "Lewati ke konten" di 15 file HTML.

Cara memeriksa: buka index.html, uji lebar 360 / 768 / 1440 px.
- Klien: 5 nama terlihat (1 dan 5 pudar) di tablet/desktop, 3 nama (1 dan 3 pudar) di HP (lebar <= 640 px); diam 2,5 dtk lalu geser satu langkah.
- Testimoni: berganti otomatis tiap 3 dtk, tanpa tombol jeda.
- Tablet 768 px: menu jadi dropdown (tidak terpotong lagi).
Foto Unsplash dan font Google butuh internet.
