# CATATAN GAMBAR

Cara mengganti: buka file HTML-nya, cari baris `<img ... src="...">` pada nomor baris di tabel, lalu ganti isi `src="..."` dengan alamat gambarmu. Di `index.html`, tiap gambar juga ditandai komentar `[GAMBAR 01]` dst. (Ctrl+F lebih andal daripada nomor baris, karena nomor bergeser kalau kamu menambah teks).

Contoh memakai gambar sendiri: simpan di folder `gambar/` sejajar dengan file HTML, lalu tulis `src="gambar/hero.jpg"`.

Semua gambar saat ini **foto contoh dari Unsplash** (dipakai ulang di beberapa halaman). Untuk web produksi, ganti dengan fotomu sendiri dan simpan di hosting sendiri. Kompres dulu (mis. squoosh.app) agar cepat di HP.

## Gambar yang tampil otomatis
- Kartu **Proyek Terbaru** dan **Artikel Terbaru** di `index.html` (GAMBAR 06 & 07) hanya cadangan. Setelah web online, fotonya diambil dari postingan teratas `proyek.html` / `artikel.html`. Untuk mengganti foto yang tampil, ganti foto di postingan itu.
- Pada `proyek.html` dan `artikel.html`, satu baris kartu = satu postingan, dan fotonya ada di `<img>` kartu tersebut. Foto besar di halaman detail ada di `proyek-1.html` dst.
- `galeri.html`: semua foto berada di satu baris panjang. Tambah foto dengan menyalin satu `<img .../>` di dalam `<div class="gallery">`.
- Sketsa Manusia/Ruang/Alam bukan file gambar; itu kode SVG (di `index.html` bagian PRINSIP dan di `prinsip.html`).
